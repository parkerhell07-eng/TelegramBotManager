# 🤖 TelegramBotManager — مدیریت کامل ربات‌های تلگرام در جیب شما

<div dir="rtl">

اپلیکیشن بومی اندروید (Kotlin + Jetpack Compose) برای مدیریت **چندین ربات تلگرام** از یک جا: موتور **پاسخ‌گویی خودکار ۲۴ ساعته** (دستورها، کلمات کلیدی و خوش‌آمد)، ارسال پیام و مدیا با کیبورد شیشه‌ای، زمان‌بندی با **تقویم شمسی**، دستیار هوشمند کسب‌وکار، آمار، **بکاپ رمزنگاری‌شده**، **آپدیت درون‌برنامه‌ای** و رابط دوزبانه (فارسی/English) با تم روشن/تیره.

## 🧠 چرا ربات من به دستورها جواب نمی‌داد؟ (و حالا چطور جواب می‌دهد)

ربات تلگرام «برنامه‌ای» نیست که خودش اجرا شود؛ فقط یک API است. تا قبل از نسخه ۲ این اپ فقط وقتی صفحه «چت‌ها» یا «پیام‌های دریافتی» باز بود پیام‌ها را می‌دید و **هیچ‌وقت خودکار پاسخ نمی‌داد**. از v2.0.0 موتور پاسخ‌گویی به‌صورت سرویس پیش‌زمینه ۲۴ ساعته فعال می‌شود:

1. وارد ربات شوید → ابزار **پاسخگویی خودکار**.
2. کلید **گوش‌دهی ۲۴ ساعته** را روشن کنید (اجازه اعلان و در صورت پرسیدن، استثنا از بهینه‌سازی باتری را بدهید).
3. دستورها + پاسخ‌شان را اضافه کنید و «ذخیره» بزنید؛ دکمه «همگام‌سازی منوی تلگرام» همان فهرست را در منوی ربات هم ثبت می‌کند.
4. `دستورهای /start`، `/help`، `/id` و `/about` به‌صورت خودکار ساخته می‌شوند؛ متن خوش‌آمد و پاسخ دستور ناشناخته هم قابل تنظیم است.
5. ابزار **بررسی سلامت** در همان صفحه سالم بودن توکن، وب‌هوک مزاحم و فعال بودن گوش‌دهی را چک می‌کند.

> نکته: برای پاسخ‌گویی پایدار، اپ را از «بهینه‌سازی باتری» مستثنا کنید (تنظیمات گوشی → باتری). اگر گوشی‌تان اپ را بکشد، با باز کردن دوباره اپ سرویس خودکار برمی‌گردد.

## ☁️ ربات ابری ۲۴/۷ روی گیت‌هاب — حتی با گوشی خاموش

مغز هر ربات تلگرام باید روی یک دستگاه همیشه‌روشن اجرا شود. این اپ آن دستگاه را **GitHub Actions** می‌کند: رایگان نامحدود برای مخزن عمومی، بدون کارت، و — برخلاف کلادفلر — **در ایران باز** (همان گیت‌هابی که آپدیت‌های اپ از آن می‌آید). فعال‌سازی:

1. وارد ربات شوید → ابزار **ربات ابری ۲۴/۷**.
2. **گام ۱**: در مرورگر یک توکن گیت‌هاب بسازید (تیک‌های `public_repo` + `workflow`) و داخل اپ بچسبانید — اپ آن را با Keystore رمزنگاری می‌کند.
3. **گام ۲**: دکمه **فعال‌سازی ربات ابری ۲۴/۷** را بزنید؛ اپ خودش یک مخزن عمومی کوچک می‌سازد، موتور پاسخ‌گو، زمان‌بند و قوانین را آپلود می‌کند، توکن ربات را با **libsodium sealed box** به‌صورت Secret ذخیره می‌کند و اولین اجرا را چک می‌کند.
4. از این لحظه هر دقیقه گیت‌هاب موتور را اجرا می‌کند و ربات **حتی با گوشی خاموش** به /start، دستورها، کلیدواژه‌ها و… جواب می‌دهد.
5. پیام کاربران به «صندوق پیام» (چت مدیر) فوروارد می‌شود؛ **ریپلای** روی هر پیام، همان متن را به آن کاربر می‌فرستد.

> امنیت: مخزن فقط موتور و قوانین را دارد؛ توکن ربات Secret رمزنگاری‌شده است و هیچ‌وقت در کد یا لاگ ظاهر نمی‌شود. قوانین را از «پاسخگویی خودکار» تغییر دهید و با دکمه «همگام‌سازی قوانین با ابر» پخش کنید. خاموش‌کردن = حذف کامل مخزن.

## ⚡ ربات همیشه فعال ۲۴/۷ — روی خود گوشی (جایگزین)

ربات مستقیم روی **خودِ گوشی** اجرا می‌شود؛ یعنی هر کسی که اپ را نصب کند، همان لحظه بدون ساخت هیچ حسابی (بدون سرور، بدون توکن اضافه) صاحب یک ربات ۲۴ ساعته است. سرویس پیش‌زمینه‌ای اپ با چهار لایه پایداری محافظت می‌شود:

1. **سرویس پیش‌زمینه چسبنده (START_STICKY)** — اگر اندروید اپ را بکشد، خودش دوباره بالا می‌آید.
2. **راه‌اندازی خودکار پس از ری‌استارت** — گوشی را خاموش/روشن کنید؛ سرویس خودش برمی‌گردد.
3. **نگه‌بان داخلی هر ۱۵ دقیقه** — اگر کشنده‌های سخت‌گیر (MIUI و…) سرویس را خواباندند، احیا می‌شود.
4. **معافیت از بهینه‌سازی باتری + شروع خودکار سازندهٔ گوشی** — با یک لمس از صفحه «ربات همیشه فعال».

مسیر: وارد ربات شوید → ابزار **ربات همیشه فعال** → کلید وضعیت را روشن کنید و چک‌لیست همان صفحه را سبز کنید (معافیت باتری، اجازه اعلان و تنظیم شروع خودکار گوشی). قوانین پاسخ‌ها (دستورها، کلمات کلیدی، خوش‌آمد) از ابزار «پاسخگویی خودکار» ویرایش می‌شود.

> نکته: در این روش ربات به **گوشی روشن و اینترنت** نیاز دارد. از داخل اعلان دائمی هم می‌توانید سرویس را با دکمه «توقف» موقتاً pause کنید (تا وقتی دوباره داخل اپ روشنش کنید، هیچ نگه‌بانی آن را روشن نمی‌کند).

## 🚀 شروع سریع

### ۱) گرفتن توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بفرستید و مراحل ساخت را کامل کنید.
3. توکن (به شکل `123456789:AAHfiqksKZ8WbR5P...`) را کپی کنید.
4. در اپ، دکمه **+** را بزنید و توکن را وارد کنید؛ اپ آن را اعتبارسنجی و ربات را ذخیره می‌کند.

### ۲) پیدا کردن chat_id مخاطب

- به ربات خود پیام بدهید (یا `/start` بفرستید).
- در اپ، وارد ربات شوید → ابزار **پیام‌های دریافتی** → دکمه پخش (▶) → `chat_id` پیام‌رسان را کپی کنید.

### ۳) ساختن اپ (Build)

**راه اول — Android Studio (پیشنهادی):**

1. پروژه را در Android Studio (نسخه Hedgehog یا جدیدتر) باز کنید.
2. صبر کنید تا Gradle Sync تمام شود.
3. دکمه **Run ▶** یا منوی `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

**راه دوم — خط فرمان:**

```bash
./gradlew assembleDebug      # APK دیباگ
./gradlew assembleRelease    # APK ریلیز (امضاشده با کلید debug برای تست)
```

خروجی: `app/build/outputs/apk/`

> ⚠️ APK ریلیزِ این قالب با کلید debug امضا می‌شود تا قابل نصب باشد. برای انتشار عمومی، یک keystore بسازید و `signingConfig` ریلیز را در `app/build.gradle.kts` تغییر دهید.

## 📤 انتشار روی گیت‌هاب

### روش گرافیکی (ساده‌ترین)

1. در [github.com/new](https://github.com/new) یک ریپوی جدید با نام `TelegramBotManager` بسازید (**بدون** README یا لایسنس).
2. در پوشه پروژه این دستورات را بزنید:

```bash
git init
git add .
git commit -m "Initial commit: Telegram Bot Manager"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/TelegramBotManager.git
git push -u origin main
```

### گرفتن APK بدون نصب Android Studio

بعد از هر push، اکشن **Build APK** اجرا می‌شود:

- تب **Actions** در ریپو → آخرین اجرا → بخش **Artifacts** → دانلود `TelegramBotManager-debug` یا `TelegramBotManager-release`.

### انتشار خودکار در Releases

کافیست یک تگ بزنید و push کنید:

```bash
git tag v1.0.0
git push origin v1.0.0
```

اکشن **Release** به‌طور خودکار APK را build کرده و در بخش **Releases** ریپو منتشر می‌کند. ✅

## 🔒 امنیت

- توکن‌ها با `EncryptedSharedPreferences` + کلید داخل **Android Keystore** رمزنگاری می‌شوند و هیچ‌جا (لاگ، سرور، حافظه ابری) ارسال یا ذخیره نمی‌شوند.
- هر درخواست فقط مستقیماً به `https://api.telegram.org` زده می‌شود (ترافیک HTTP مسدود است) — هیچ سرور واسطی در بین نیست و توکن‌ها فقط بین گوشی شما و تلگرام جابه‌جا می‌شوند.
- مجوزهای حداقلی: `INTERNET` (API تلگرام و گیت‌هاب)، `POST_NOTIFICATIONS` (اعلان سرویس پاسخ‌گویی)، `FOREGROUND_SERVICE(_DATA_SYNC/_SPECIAL_USE)` (موتور ۲۴ ساعته)، `RECEIVE_BOOT_COMPLETED` (اجرای خودکار پس از ری‌استارت)، `REQUEST_INSTALL_PACKAGES` (آپدیت درون‌برنامه‌ای) و `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` (فقط با تأیید خود کاربر، برای پایداری سرویس). بدون دسترسی به مخاطب، موقعیت یا فایل‌ها (بکاپ از طریق فایل‌پیکر سیستمی است).
- `allowBackup=false` است تا توکن‌ها وارد بکاپ سیستمی نشوند؛ بکاپِ برنامه‌ای کاملاً رمزنگاری‌شده و فقط با رمز عبور خودتان قابل بازیابی است.
- **هرگز** فایل `local.properties` یا APK منتشرشده خود را حاوی توکن واقعی قرار ندهید — توکن‌ها فقط داخل اپ وارد می‌شوند.

### 🗝️ امضای نسخه‌های Release

برای اینکه آپدیت‌ها **بدون حذف نسخه قبلی** نصب شوند، اندروید باید همه APKها با **یک کلید ثابت** امضا شوند. کلید Release این پروژه در مسیر `keystore/release.keystore` داخل همین مخزن نگهداری می‌شود (رمز آن در `keystore/keystore.properties`):

- اگر مخزن را **عمومی (public)** نگه می‌دارید، بدانید هرکس به مخزن دسترسی داشته باشد می‌تواند با همین کلید APK امضا کند. برای امنیت بیشتر، بهتر است مخزن را خصوصی کنید یا کلید را به GitHub Secrets منتقل کنید.
- انتقال به GitHub Secrets: در تنظیمات مخزن چهار secret به نام‌های `KEYSTORE_BASE64` (معادل base64 فایل keystore)، `KEYSTORE_PASSWORD`، `KEYSTORE_ALIAS` و `KEY_PASSWORD` بسازید — workflowها به‌صورت خودکار از آن‌ها استفاده می‌کنند (اولویت با secrets است).
- اگر روزی کلید را عوض کردید، کاربران باید یک‌بار نسخه قبلی را حذف کنند؛ پس از آن آپدیت‌های بعدی دوباره بدون حذف نصب می‌شوند.

| در «پیام‌های دریافتی» چیزی نمی‌آید | وب‌هوک فعال است؛ از ابزار وب‌هوک آن را حذف کنید |
